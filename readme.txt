== Description ==
 
The Interactive Offers Co-Registration Plugin allows easy installation of the Co-Registration iframe.  
 
== Installation ==
  
1. Upload `cia_intof_io.php` to the `/wp-content/plugins/` directory
1. Activate the plugin through the 'Plugins' menu in WordPress
1. Place [cia_intof] in your templates where the Co-Registration iframe is to be displayed.
